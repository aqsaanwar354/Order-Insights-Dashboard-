# 📊 Order Insights Dashboard

A Python-based data analysis project that cleans, analyzes, and visualizes online store order data using an interactive Streamlit dashboard.

## 🛠️ Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## ✨ Features
- Data exploration and quality inspection
- Data cleaning and preprocessing
- Statistical analysis (Mean, Median, Standard Deviation)
- Sales analysis by region and category
- Data visualizations
- Interactive Streamlit dashboard with region filtering

## 📂 Project Structure
```text
Order-Insights-Dashboard/
├── data/
├── output/
├── explore.py
├── cleaning.py
├── analysis.py
├── visualization.py
├── app.py
├── requirements.txt
└── .gitignore
```

## 🚀 Installation & Usage

**1. Clone the repository**
```bash
git clone https://github.com/aqsaanwar354/Order-Insights-Dashboard.git
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the dashboard**
```bash
streamlit run app.py
```
